# Standard TREE continue

The separate checkout publication page is retired. `/checkout-setup` redirects to the game.

When a flight runs out of lives, sign in on the game page and choose **CONTINUE — 20,000 TREE**. Approve one standard TREE transfer, with SUI gas shown separately. The server reads its finalized checkpoint, sender, TREE balance changes, recipient and saved-flight reference before the existing one-time delivery restores 3 lives. Wave and score remain unchanged; continued flights are casual and cannot qualify for ranked scores.

No new Move package, quote signer, admin publication or support report is required by this payment implementation. Slush's independent website security verdict has not been cleared by this change. If the wallet shows its malicious-site warning, choose Return to safety; the app must not bypass that warning.

Sales remain controlled by the existing server-side pilot policy. No wallet signature or actual transfer is performed by development checks.
